# HD Profile Viewer (Chrome Extension)

دریافت عکس پروفایل اینستاگرام با بالاترین کیفیت موجود.
Get an Instagram profile picture in the highest available quality.

## نصب / Install

1. این مخزن را با دکمه **Code → Download ZIP** دانلود و از حالت فشرده خارج کنید.
   Download this repo via **Code → Download ZIP** and extract it.
2. در کروم `chrome://extensions` را باز کنید.
   Open `chrome://extensions` in Chrome.
3. **Developer mode** را روشن کنید.
   Turn on **Developer mode**.
4. روی **Load unpacked** بزنید و پوشه‌ای که `manifest.json` داخلش است را انتخاب کنید.
   Click **Load unpacked** and select the folder containing `manifest.json`.

## استفاده / Usage

صفحه instagram.com را باز کنید، روی آیکون اکستنشن کلیک کنید، نام کاربری را وارد کنید و «دریافت HD» را بزنید.
Open instagram.com, click the extension icon, enter a username and press the HD button.

## توضیحات فنی / Notes

- Chrome 111 یا بالاتر لازم است. / Requires Chrome 111+.
- اکستنشن از ساختار داخلی اینستاگرام استفاده می‌کند و ممکن است با آپدیت‌های اینستاگرام از کار بیفتد.
  It relies on Instagram's internal structure and may break after Instagram updates.
- هیچ داده‌ای به سرور شخص ثالث ارسال نمی‌شود. / No data is sent to third-party servers.
