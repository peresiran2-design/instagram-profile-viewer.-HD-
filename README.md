# HD Profile Viewer (Chrome Extension)

دریافت عکس پروفایل اینستاگرام با بالاترین کیفیت موجود.

&nbsp;

Get an Instagram profile picture in the highest available quality.

---

## نصب

1. این مخزن را با دکمه **Code ← Download ZIP** دانلود کنید و از حالت فشرده خارج کنید.
2. در مرورگر کروم آدرس `chrome://extensions` را باز کنید.
3. گزینه **Developer mode** (بالا سمت راست) را روشن کنید.
4. روی **Load unpacked** بزنید و پوشه‌ای که `manifest.json` داخل آن است را انتخاب کنید.
5. (اختیاری) آیکون پازل کروم را بزنید و اکستنشن را پین کنید.

&nbsp;

## Installation

1. Download this repository using **Code → Download ZIP** and extract it.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the folder that contains `manifest.json`.
5. (Optional) Click the puzzle icon in Chrome and pin the extension.

---

## نحوه استفاده

1. وارد سایت instagram.com شوید (ترجیحاً صفحه پروفایل کاربر مورد نظر).
2. روی آیکون اکستنشن کلیک کنید.
3. نام کاربری را وارد کنید (اگر در صفحه پروفایل باشید، خودکار پر می‌شود).
4. روی **دریافت HD** بزنید.
5. با **دانلود مستقیم (JPG)** عکس را ذخیره کنید یا با **باز کردن لینک اصلی** در تب جدید ببینید.

&nbsp;

## Usage

1. Open instagram.com (preferably the profile page of the target user).
2. Click the extension icon.
3. Enter the username (it is filled in automatically on a profile page).
4. Click **دریافت HD** (Get HD).
5. Save the picture with **دانلود مستقیم (JPG)** (direct download) or open it in a new tab with **باز کردن لینک اصلی** (open original link).

## Technical Notes

1. Requires Chrome 111 or later.
2. It relies on Instagram's internal structure and may stop working after Instagram updates.
3. No data is sent to third-party servers.
